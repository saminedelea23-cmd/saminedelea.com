============================================================================
 CRM — CÓMO LLEGAN TUS LEADS (Google Forms + Google Sheets)
============================================================================
Tu web ya está conectada a tu Google Form. Cada persona que rellena el
formulario de la web aparece sola, automáticamente, como fila nueva en tu
Google Sheet. No tienes que tocar nada más para que esto funcione.

Tienes DOS pestañas en tu hoja:
  - "Respuestas de formulario 1": el registro en bruto, lo crea Google
    solo. No la toques, es solo el almacén de datos.
  - "Seguimiento": tu panel de trabajo (ver PASO siguiente si todavía no
    lo has creado) — aquí es donde marcas Contactado / Estado / Importe
    cerrado / Notas para cada lead.

============================================================================
 ¿CÓMO SÉ SI LOS DATOS ESTÁN LLEGANDO?
============================================================================
Abre tu Google Sheet (la que enlazaste a tu Google Form) → pestaña
"Respuestas de formulario 1". Cada envío real del formulario de la web
aparece ahí como una fila nueva, con fecha y hora.

Si alguien dice que ha rellenado el formulario y no ves nada:
  1. Comprueba que la web en Netlify tiene la última versión subida
     (vuelve a arrastrar la carpeta si tienes dudas).
  2. Abre la consola del navegador (F12) en la web y mira si hay algún
     error en rojo al pulsar "Continuar" en el último paso del formulario.

============================================================================
 PASO — Crea (o revisa) tu panel "Seguimiento"
============================================================================
Esto es tuyo para gestionar el pipeline a mano: Contactado sí/no, Estado
(Pendiente / Contactado / Cerrado / Perdido), cuánto dinero si cierras, y
notas. Si ya lo tienes montado, no hace falta repetir esto.

1. En tu Google Sheet → Extensiones → Apps Script.
2. Borra lo que haya y pega esto:

function onFormSubmitSami(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var values = e.namedValues;
  var seg = ss.getSheetByName('Seguimiento');
  if (!seg) {
    seg = ss.insertSheet('Seguimiento');
    seg.appendRow(['Fecha', 'Nombre', 'Email', 'Teléfono',
      'Capital a invertir', 'Contactado', 'Estado',
      'Importe cerrado (€)', 'Notas']);
  }
  function get(field) {
    return values[field] ? values[field][0] : '';
  }
  seg.appendRow([
    new Date(),
    get('Nombre'),
    get('Email'),
    get('Teléfono'),
    get('Capital a invertir'),
    'No',
    'Pendiente',
    '',
    ''
  ]);
}

3. Guarda (Ctrl+S).
4. Icono del reloj ("Activadores" / "Triggers") en el menú de la
   izquierda → "+ Añadir activador" (abajo a la derecha).
5. Configura:
     - Función: onFormSubmitSami
     - Origen del evento: Desde la hoja de cálculo
     - Tipo de evento: Al enviar formulario
6. Guardar → Google te pide autorizar, dale permiso (es tu propio
   script, es seguro).

Listo. A partir de ahora, cada lead nuevo aparece automáticamente en
"Seguimiento" con estado "Pendiente" y "Contactado: No". Tú vas
cambiando esas dos columnas a mano según trabajes cada lead (Contactado:
Sí/No — Estado: Pendiente/Contactado/Cerrado/Perdido), y si cierras,
pones el importe en "Importe cerrado (€)".

Truco opcional: selecciona la columna "Estado" → Datos → Validación de
datos → Lista de elementos → escribe: Pendiente, Contactado, Cerrado,
Perdido → así te sale un desplegable en vez de escribir a mano.

============================================================================
 ¿Y CALENDLY?
============================================================================
Se queda igual, solo para que la gente reserve la hora de la llamada. Los
DATOS de contacto (nombre, email, teléfono, capital, etc.) ya no dependen
de Calendly para nada: llegan directos y fiables a tu Google Sheet en
cuanto alguien termina el formulario de la web, antes incluso de que
reserve la llamada.

============================================================================
 ¿PUEDO EDITAR LA HOJA, AÑADIR COLUMNAS, CAMBIAR COLORES?
============================================================================
Sí, es una hoja de cálculo normal tuya. Solo no borres ni renombres las
pestañas "Respuestas de formulario 1" ni "Seguimiento", ni cambies los
nombres de las columnas que usa el script (Nombre, Email, Teléfono,
Capital a invertir) o dejará de rellenarlas bien.
