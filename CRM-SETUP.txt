============================================================================
 CONECTAR EL FORMULARIO A GOOGLE SHEETS (tu "CRM" gratuito)
============================================================================
Cada vez que alguien complete el formulario de la web (nombre, email,
WhatsApp, edad, ingresos, capital, ocupación, disponibilidad y su
respuesta), aparecerá como una fila nueva en una hoja de cálculo tuya.
No necesitas darme acceso a tu cuenta de Google en ningún momento.

PASO 1 — Crea la hoja
----------------------
1. Ve a sheets.google.com y crea una hoja nueva en blanco.
2. Ponle el nombre que quieras, por ejemplo "Leads Sami Nedelea".

PASO 2 — Pega el script
------------------------
1. Dentro de la hoja, ve a Extensiones → Apps Script.
2. Borra todo lo que haya en el editor y pega esto tal cual:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(['Fecha', 'Nombre', 'Email', 'WhatsApp', 'Edad',
      'Ingresos actuales', 'Capital a invertir', 'Ocupación',
      'Disponibilidad', 'Por qué quiere empezar']);
  }
  // La web envía los datos como un formulario real (e.parameter.payload);
  // se deja también el formato antiguo (e.postData.contents) por si acaso.
  var data;
  if (e.parameter && e.parameter.payload) {
    data = JSON.parse(e.parameter.payload);
  } else {
    data = JSON.parse(e.postData.contents);
  }
  sheet.appendRow([
    new Date(),
    data.nombre || '',
    data.email || '',
    (data.prefijo || '') + ' ' + (data.telefono || ''),
    data.edad || '',
    data.ingresos || '',
    data.capital || '',
    data.ocupacion || '',
    data.disponible || '',
    data.situacion || ''
  ]);
  return ContentService.createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}

3. Arriba, dale un nombre al proyecto (ej. "Formulario web") y guarda
   (icono de disquete o Ctrl+S).

PASO 3 — Publícalo como "Aplicación web"
------------------------------------------
1. Botón azul "Implementar" (arriba a la derecha) → "Nueva implementación".
2. En "Seleccionar tipo" pulsa el engranaje ⚙ y elige "Aplicación web".
3. Configura:
     - Descripción: lo que quieras.
     - Ejecutar como: Yo (tu cuenta).
     - Quién tiene acceso: Cualquier usuario.
   (Esto es necesario para que la web pueda enviar datos; nadie puede leer
   tu hoja desde ahí, solo añadir filas a través del formulario.)
4. Pulsa "Implementar". Google te pedirá autorizar el script la primera
   vez — dale permiso (es tu propio script, es seguro).
5. Te dará una URL que termina en "/exec". Cópiala entera.

PASO 4 — Pégamela a mí, o ponla tú misma
-------------------------------------------
Mándame esa URL y yo la pongo, o edítala tú directamente: abre index.html
con un editor de texto, busca "GOOGLE_SHEETS_URL" (cerca del final) y
sustituye el valor de ejemplo por tu URL real, entre comillas.

Hasta que no pongas esa URL, el formulario sigue funcionando con
normalidad pero no envía nada a ningún sitio (solo lo verías en la consola
del navegador, F12, si abrieras esa pestaña).

¿Quieres editar la hoja más adelante, añadir columnas, cambiar colores,
poner filtros? Es una hoja de cálculo normal tuya — haz lo que quieras,
el script solo añade filas al final.

============================================================================
 YA TENÍA EL SCRIPT PUESTO Y HA CAMBIADO — ¿CÓMO LO ACTUALIZO?
============================================================================
Si ya habías hecho estos pasos antes y el código de arriba ha cambiado
(por ejemplo, para arreglar un fallo), NO hace falta crear una implementación
nueva (eso te daría una URL distinta y tendrías que volver a configurarla).
Solo:

1. Abre tu hoja → Extensiones → Apps Script.
2. Borra el código viejo y pega el nuevo (el de más arriba en este archivo).
3. Guarda (Ctrl+S).
4. Botón "Implementar" → "Gestionar implementaciones".
5. Pulsa el icono del lápiz (editar) sobre tu implementación activa.
6. En "Versión", elige "Nueva versión".
7. Pulsa "Implementar".

Tu URL (la que termina en /exec) NO cambia — sigue siendo la misma de
siempre, solo que ahora ejecuta el código actualizado.

============================================================================
 ¿CÓMO SÉ SI LOS ENVÍOS ESTÁN LLEGANDO?
============================================================================
Esto es lo más útil para comprobar si algo falla:

1. Abre tu hoja → Extensiones → Apps Script.
2. En el menú de la izquierda, pulsa el icono del reloj ("Ejecuciones").
3. Ahí ves cada vez que alguien ha enviado el formulario:
     - Si no aparece NADA después de que alguien lo haya rellenado en la
       web → el envío no está llegando a Google (puede ser que la web en
       vivo tenga una versión antigua sin esta conexión: vuelve a subir la
       carpeta a Netlify para estar segura).
     - Si aparece pero en rojo/con error → ábrela y mira el mensaje de
       error, mándamelo y lo arreglamos.
     - Si aparece en verde ("Completado") → el dato se guardó bien; revisa
       que estás mirando la pestaña/hoja correcta (abajo del todo, las
       pestañas de tu documento).
